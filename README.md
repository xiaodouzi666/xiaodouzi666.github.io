## Publish a learning note

Create an English Markdown file in `_posts/`, named `YYYY-MM-DD-short-title.md` using the publication date. Start with:

```markdown
---
title: "Your post title"
description: "An optional one-sentence summary."
---

Write the note here in Markdown.
```

For a piece already published elsewhere, add `external_url: "https://…"` to the front matter. The blog index will link directly to the original.

Commit the file to `main`. GitHub Pages builds the [blog index](https://xiaodouzi666.github.io/blog/) automatically, newest first.
